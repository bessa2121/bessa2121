### ⚙️ [Microservices Architecture — Java Spring Boot](https://github.com/bessa2121/Microservi-os_DIO)

Production-style microservices project with two independent services communicating via REST and async messaging.

| Service | Responsibility |
|---|---|
| 🏭 Warehouse | Inventory and stock management |
| 🛍️ Storefront | Product showcase and catalog |

- 📨 Async communication via **RabbitMQ**
- 🐳 Full containerization with **Docker + Docker Compose**
- 📄 API documentation via **Swagger/OpenAPI**
- 🗃️ Persistence with **Spring Data JPA + PostgreSQL**

**Stack:** `Java` `Spring Boot` `Spring Data JPA` `RabbitMQ` `Docker` `PostgreSQL` `Swagger`
